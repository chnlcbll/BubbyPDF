# Launch plan

Nothing has been published. Every step below is yours to approve.

1. **Before:** sign the installer (see `deploy.md`), run the trademark checks in `brand.md`, re-test on a second Windows PC.
2. **Host:** a GitHub repository with Releases for the two .exe files, plus a one-page site (GitHub Pages) from `landing.md`.
3. **Feedback channel:** GitHub Issues. The app has no telemetry by design, so ask.
4. **Where people already ask for this:** Reddit threads searching for a free PDF editor or for alternatives to subscription PDF tools, and Hacker News (the 135 comments in `reviews.csv` show the recurring threads). Post as the maker, answer the question asked, and don't spam.
5. **Show HN / Product Hunt:** lead with the fix: "A free, offline PDF editor for Windows: fill, sign, edit, merge. No account."
6. **First 10 users:** people you know who fill and sign forms (rental applications, school forms, invoices). Watch them use it once and note where they hesitate.
